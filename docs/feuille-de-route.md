# Feuille de route

| Phase | Contenu | État |
|---|---|---|
| 1. Fondations | Structure, configuration, ports, routeur d'IA, mémoire éditoriale, agent et validation, tests, CI | Fait |
| 2. Couche IA | Adaptateurs Gemini (principal) et Groq (secondaire), basculement, délais d'attente, clés en variables d'environnement | Fait |
| 2 bis. Autres fournisseurs | OpenRouter, Ollama (local), OpenAI (optionnel) | Plus tard |
| 3. Contenu | Veille, actualités, tendances, choix du sujet, scénario, vérification | À faire |
| 4. Production vidéo | Visuels, voix, sous-titres, montage au format 9:16 | À faire |
| 5. Publication | Connexion Facebook (API Graph), notification de validation | À faire |
| 6. Interaction | Commentaires, statistiques, optimisation de la stratégie | À faire |
| 7. Autonomie | Passage progressif en mode `auto` quand la fiabilité est démontrée | À faire |

Chaque phase est livrée avec ses tests et sa documentation.
